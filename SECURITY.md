# Security

Encaixe stores CVs, contacts and hiring decisions, so security reports are welcome and handled first.

- **Report privately** through GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability").
  Please do not open a public issue for a vulnerability.
- Include what you found, how to reproduce it and what an attacker could reach (for example, another person's profile or contact).
- You will get an answer within a few days. Fixes ship as soon as they are ready, and the report is credited unless you prefer otherwise.

Scope: the code in this repository and the official deployment. Third-party job boards and the e-mail and LLM providers are out of scope.
